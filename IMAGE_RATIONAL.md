# Image Curation & Rejection Rationale

## Core Visual Rule
"The code output is the visual anchor. Decorative graphics reduce technical credibility."

## Rejected Visual Artifacts

1. **AI-Generated Cyber Security / Network Artwork**
   - *Attempted:* Dark abstract 3D network nodes and glowing keyhole graphics.
   - *Reason for Rejection:* Generic marketing visuals convey zero technical information about middleware construction or prompt engineering performance.

2. **Abstract Gradient Overlays**
   - *Attempted:* Gradient wave textures for the background.
   - *Reason for Rejection:* High-contrast whitespace ensures the focus remains entirely on the work and metrics without visual clutter.

## Final Visual Selection
The single primary visual asset on the site is a direct dark-mode terminal rendering of Section 3.2 stdout from `w03_data_contract.ipynb`. The contrast between the dark terminal container (`#0F172A`) and the light canvas (`#F8FAFC`) draws the user's eye directly to the verified metric (`100.0% rule agreement`).
